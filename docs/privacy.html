RTDB Tree Editor — Privacy Policy

Effective October 28, 2026
In short: the extension does not collect, sell or share your data. It talks only to the Firebase Realtime Database you open in the Firebase console, using your own console session, and keeps everything else on your computer.

What the extension does

RTDB Tree Editor adds a Tree editor tab to the Realtime Database section of the Firebase console (console.firebase.google.com). It reads the data at the path you are viewing, lets you edit it as a tree, and writes it back when you click Publish.

Information the extension handles

  • Your Firebase console session credential. To read and write your database with exactly the permissions you already have in the console, the extension picks up the access credential that the console itself sends to Realtime Database (*.firebaseio.com / *.firebasedatabase.app). It only looks at traffic to those database hosts. The credential is kept in the browser's memory (chrome.storage.session), is cleared when the browser closes, and is sent only to the Realtime Database you are editing.
  • Your database content. Data at the path you open is loaded into the editor so you can work with it. It is sent back only to that same database, and only when you publish.
  • Rollback snapshots. Before each publish, the previous data at that path is saved in the extension's local storage (chrome.storage.local) on your computer so you can roll back. You can delete snapshots at any time from History, or by removing the extension.
  • Preferences. Settings such as whether auto-sync is on are stored locally.

What the extension does not do

  • It does not send any data to the developer or to any third-party server.
  • It has no analytics, tracking, advertising or remote code.
  • It does not sell, rent or transfer your data, and does not use it for any purpose other than the editing features described above.
  • It does not read other websites; it only runs on the Firebase console and only contacts Realtime Database hosts.

Chrome Web Store User Data Policy

The use of information received by this extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.
