# Changelog

## 0.2.0
- Find & replace (Ctrl/⌘+F): substring search in values and/or key names, optional match case, next/previous, Replace and Replace all (one undo step).

## 0.1.0
- First release: open `.json` files as an editable tree (add, duplicate, remove, rename, edit values, drag to reorder arrays, fold/unfold), using VS Code's own save, dirty state and undo/redo.
