RTDB Tree Editor · Chrome

Adds a Tree editor tab to Realtime Database in the Firebase console, so you can edit data as a tree — add, duplicate, reorder, live sync — and publish it back. Works in Chrome, Edge, Brave and other Chromium browsers.

  1. Install it from the Chrome Web Store and click Add to Chrome.
    Open in Chrome Web Store
  2. Open the Firebase console (reload the tab if it was already open) and go to Realtime Database → Data.
  3. Click the new Tree editor tab next to Data. It loads the node you were viewing — no sign-in or setup needed.
Updates install automatically from the Chrome Web Store. Your edits are only written when you click Publish, and every publish can be rolled back from History.

JSON Tree Editor Plus · VS Code

The same tree editor for .json files in VS Code — add, duplicate, rename, drag to reorder — with VS Code's own save, undo and Git.

  1. Install it from the VS Code Marketplace (or search “JSON Tree Editor Plus” in the Extensions view).
    Open in VS Code Marketplace
  2. Open a .json file and click the tree icon in the editor's top-right, or right-click the file → Open as JSON Tree.
