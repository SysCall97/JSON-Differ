Install the RTDB Tree Editor extension

Adds a Tree editor tab to Realtime Database in the Firebase console, so you can edit data as a tree and publish it back. Works in Chrome, Edge, Brave and other Chromium browsers.

  1. Download and unzip the extension. Keep the unzipped folder somewhere permanent (not Downloads) — Chrome loads it from there.
    ⬇ Download extension
  2. Open the extensions page. Click the link below; if your browser blocks it (most do for websites), it is copied — paste it into the address bar and press Enter.
    chrome://extensions Copied — paste it in the address bar
  3. Turn on “Developer mode” (switch in the top-right of that page).
  4. Click “Load unpacked” (top-left) and select the unzipped rtdb-tree-editor folder (the one that contains manifest.json).
  5. Reload your Firebase console tab, open Realtime Database → Data, and click the new Tree editor tab.
Updating: download again, replace the folder's contents, then click the ↻ reload icon on the extension's card in the extensions page and reload the console tab.
